> [!WARNING]
>
> ### Антивирусные предупреждения
> Антивирус может отреагировать на WinDivert.  
> Для работы zapret нужен WinDivert — средство перехвата и фильтрации сетевого трафика.
> Его применяют как легальные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит WinDivert к программам повышенного риска или хакерским инструментам. В таких случаях файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку с zapret в антивирусные исключения либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». При корректной настройке исключений рекомендуется добавить исключение. Если вы не уверены в своих действиях, безопаснее отключить обнаружение PUA.

## ⚙️ Использование

1. Включите безопасный DNS (Secure DNS).
    * В Chrome включите «Использовать безопасный DNS» и укажите DNS-провайдера, отличного от «Поставщика по умолчанию».
    * В Firefox откройте «DNS через HTTPS», выберите режим «Персональный», затем «Выбрать провайдера/поставщика» и вручную введите URL. Например: `https://dns.google/dns-query`; Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно настроить в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется пользователям Windows 11.
    * На роутере Keenetic активируйте настройку «Транзит запросов». Если она выключена, Secure DNS на компьютере может работать некорректно или не настраиваться.

2. Загрузите ZIP- или RAR-архив с [последнего релиза](https://github.com/cresthelperenhance12/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте «Разблокировать». При распаковке через 7-Zip или PeaZip этот шаг не требуется.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу или специальные символы.

5. Запустите подходящий файл.
    * Чтобы найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы добавить стратегию в автозапуск: **`service.bat`** -> `Install Service` -> выберите подходящую стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную.

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому переберите варианты (**ALT**, **FAKE** и другие), пока не найдёте подходящий.

- [**`service.bat`**](./service.bat) — автозапуск стратегий и другие инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (службы `services.msc`)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — включить или отключить обход для игр и других служб, работающих с UDP и TCP на портах выше 1023.  
  После смены режима перезапустите стратегию.  
  Текущее состояние указано в скобках (включено/выключено).
  - **`IPSet Filter`** — настроить обход сервисов из `ipset-all.txt`.  
  Этот режим может помочь при проверке ресурса, который доступен без zapret, но не работает с ним.  
  В скобках отображается текущее состояние:
    - `none` — проверка не применяется ни к одному IP-адресу
    - `loaded` — IP проверяются по списку
    - `any` — фильтр применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины сбоев zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`. Это может помочь, если Discord внезапно перестал работать.
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️ Частые вопросы и неполадки

### После запуска `general*` ничего не происходит

- При отдельном запуске стратегии (не через service) должен появиться процесс обхода `winws.exe`, видимый на панели задач.  
Если процесса нет, обратитесь к [#522](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues/522).

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте текст из открывшегося Блокнота.
  - Откройте файл `hosts` в созданной папке с помощью текстового редактора, запущенного от имени администратора.
  - Вставьте скопированное в конец `hosts` или замените аналогичные записи, добавленные ранее.
  - Сохраните файл и проверьте соединение. Если проблема осталась, убедитесь, что изменения действительно сохранены.

#### Результат не гарантирован. Если способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/cresthelperenhance12/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Обнаружение может сделать неэффективной стратегию, которая раньше работала.
> В репозитории есть несколько вариантов обхода. Если ни один не подходит, создайте собственную стратегию, взяв за основу одну из имеющихся и изменив её параметры.
> Описание параметров приведено [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки.

- Убедитесь, что ресурс указан в списке доменов или IP-адресов.

- Испытайте другие варианты (**`ALT`**, **`FAKE`** и прочие).

- Выполните полную переустановку по инструкции ниже.

- См. [#765](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните ошибки, если они есть, и в конце введите Y.
- Удалите папку zapret.
- Загрузите свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/cresthelperenhance12/zapret-discord-youtube/releases).
- Нажмите правой кнопкой по архиву, откройте свойства. Если внизу справа есть флажок «Разблокировать», отметьте его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новую папку в корне диска. В пути не должно быть пробелов или специальных символов.
- По очереди запускайте разные скрипты `general` и проверяйте нужные интернет-ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- Когда найдёте подходящую стратегию, добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Другие значения могут повлиять на доступ к ресурсам, которые вы не собирались фильтровать.

### Античит сообщает о WinDivert

- Следуйте [инструкции](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) файлами с теми же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### WinDivert остаётся в списке служб после удаления через [**`service.bat`**](./service.bat)

1. В командной строке Windows найдите имя службы. Откройте её через Win+R, введя `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив имя из первого шага:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что включён [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: YouTube, как известно, начал с ними бороться.
- Попробуйте остальные стратегии, особенно если раньше всё работало.
- Также см. [#251](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8F-использование).
- Сначала выясните, какая стратегия открывает YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если Discord не работает и в браузере, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- Также см. [#252](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/cresthelperenhance12/tg-ws-proxy).
- Другой вариант — бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

В большинстве случаев можно начать так:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если это не помогло, включите настройку `ipset any`.

Учтите: с `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Выясните IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions), а не issue, и дождитесь ответа других игроков.

### Здесь нет решения моей проблемы

- Опишите проблему [здесь](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Чтобы расширить список адресов для обхода, добавляйте записи в соответствующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например если адрес сети добавлен в `ipset-all.txt`, но отдельный домен из этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
